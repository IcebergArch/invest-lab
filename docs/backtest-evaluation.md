# 日线回测评估口径

`quant_lab research` 和 `quant_lab run` 会在 `research.json` 旁写出可直接阅读的
`backtest.md`。结构化报告保存策略参数、数据截止日、价格输入 SHA-256、最新日行情的
`run_id / payload_hash / fetched_at`，以及回测结果。相同输入哈希用于识别已被更新的
历史行情，但当前 SQLite 仍会覆盖旧值；它尚不能充当不可变数据快照。

## 同期对照

- 策略：`t` 日收盘产生目标，`t+1` 日收盘代理成交，收益从随后区间开始；
  建仓及调仓按目标权重与漂移后权重的绝对差计费。
- 同股票池等权买入持有：同样在第二个收盘价建仓，之后不再平衡；建仓使用与策略
  相同的每单位成交额费用。此对照用于判断策略是否优于持有**这几只股票**。
- 沪深 300：仅当指数与股票日期完整对齐时展示相同起止日期的价格指数变化；
  费用设为零，作为市场背景，而非可成交交易品种或等价策略。缺日期则明确标为不可用。

报告列出累计收益、年化收益、最大回撤、年化波动和策略累计换手。累计换手是每期
成交额相对当期权益的比例之和，不能读作交易次数或对初始本金的总倍数。

## 时间切分

当共同交易日不少于 252 个时，报告按约 70% / 30% 的时间顺序展示前段和后段表现。
切分直接复用完整回测的真实仓位与权益路径；后段从分界日权益重新计 1，避免在分界日
重新建仓或漏计跨界持仓。当前参数与股票池没有在分界日之前预先登记，因此这个后段
仅是**回看诊断**，不是独立样本。`prospective_out_of_sample.status=pending` 直到规则、
数据版本和评价门槛冻结后积累真实的新交易日。

## 当前真实链路核对（2026-09-29）

实际运行 `PYTHONPATH=src python3 -m quant_lab research sma-trend`，数据库中三只重点
股票各有 1391 个日线，日期覆盖 2021-01-04 至 2026-09-28；沪深 300 与它们在该区间
完整对齐。末日股票行情可关联同步批次
`1273182577ac4644aea76e88c618516c`。当前回测输入哈希为
`c363ebe0c9670223a1bff35512e6a44abaf70d5594fea777209ad554062028b7`。
具体收益和回撤以当次 `backtest.md` 与 `research.json` 为准。

这条链路仍有三个重要缺口：三股样本存在事后选择偏差；多数历史股价来自腾讯，最近
少数来自东方财富，尚未逐日跨源对账；日线与统一费率无法模拟涨跌停、停牌、费用拆分
和 10:30 成交。扩展到公开数据集时，先保留源仓库版本、文件哈希、复权口径、股票历史
成员与交易日缺失记录，再比较模型；无历史成员或仅存当前上市股票的数据集不得用来
证明全市场选股策略收益。
