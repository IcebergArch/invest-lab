# 预测稳定性分层审计

`quant_lab.forecast_stability` 对同一股票、起点、目标日及预测步长的模型与随机游走预测做配对比较。误差改善 `1 - 模型绝对收益误差总和 / 随机游走绝对收益误差总和` 大于零才表示模型在这些配对样本上改善。95% 区间按**整个起点日历年**重抽，保留同年股票之间的共同冲击；即使这样，少量年份的区间也不等于可靠的独立样本外证明，更不代表交易收益。

## 三档及门槛

| 等级 | 判定 | 结果 |
| --- | --- | --- |
| 广域稳定 | 全部配对样本的数量、股票、年份、区块数、覆盖率达标且按年重抽区间下界大于零；事件应激样本也达标且下界大于零；应激类型至少覆盖三个预先登记且经核验的不同类别；模型提供者完整就绪；另有与模型版本、实验输入、步长和评估区间绑定的事前冻结与事后成熟的 PIT/前瞻验证记录 | 仍只供研究，须再做可交易性、费用和风险回测 |
| 限定范围 | 预先登记的股票或起点日期过滤器实际筛出严格子集；**范围内全部样本**达标，包括其中的事件应激样本；声明早于首个范围内预测起点，模型版本此前冻结；有与范围哈希、实验输入和步长一致的成熟 PIT/前瞻验证记录 | 范围外弃答；范围内仍只供研究 |
| 粗预测/证据不足 | 任一所需条件缺失 | 弃答，不作可执行预测 |

默认阈值为全样本至少 100 条、10 只股票、5 个起点年份、5 个年度区块、90% 随机游走样本覆盖率；广域档还要求事件应激至少 20 条、3 个年度区块、3 种独立登记且各有至少 5 条模型样本的应激类型。股票年区块数只作为诊断显示，不作为独立证据数量。指标以完整配对样本计算，不用事后剔除事件的“普通阶段”指标升档。事件前 `-5` 到后 `+20` 交易日标签只用于回看诊断；未来突发政策的事件日不能事前获知。

验证记录必须包含声明记录 ID、声明时间、模型冻结时间、验证完成时间、模型名/版本、实验键与输入指纹、步长、首个起点、最后目标日，以及 PIT/前瞻验证状态。限定范围另以规范化过滤器 SHA-256 绑定；广域档的多类型事件分类也须预先登记，并与验证记录中的分类哈希一致。审计函数核对这些字段的时间顺序和数据关联；**调用方仍须独立核验声明、验证和事件分类记录确实在相应时间生成且不可被修改**。默认的可信来源标志均为 `false`，控制台 API 不接收这些标志或任何客户端提供的验证记录。自报布尔值、一个声明 ID 或事后发现的高分子集均不能单独升档。

本分层仅是预测证据。股票可交易状态、费用、滑点、政策黑天鹅及群体交易行为需要其他数据和策略测试；收盘价模型不能识别机构身份。

## 已保存的真实审计（2026-09-29）

来源是 Qlib 复权收盘价实验 `e3386e2482764d54848b13909cf2d959`（Chronos-Bolt Tiny）、`cf330a7f350741a698149a3cd19214c1`（TimesFM 2.5）以及事件研究 `5140698b270c4bdd8502d6dedefb18fb`。三个源文件均通过各自读取器的哈希检查；事件标签截到预测日历结束日。以下审计 JSON/Markdown 也已读回校验。
