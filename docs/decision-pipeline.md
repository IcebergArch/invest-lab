# 决策链与预算契约

目标逻辑：**原始数据 → 点时校验与清洗 → 因子计算 → 单函数策略或多函数汇聚策略 → 资金/风险预算约束 → 模拟执行 → 结果评估 → 下一版本研究**。两种策略都输出同一种日期化目标仓位，执行与收益统计共用一套引擎。

“事件”在此不是必备中间层。财报、政策、公告、价格异动等信息可以作为有发布时间和来源的数据输入，经确定的算法转换为因子；每个决策函数可使用一个或多个因子。单函数策略直接形成目标仓位；多函数策略由各函数给出同一时点、同一股票池的提案，版本化的汇聚规则综合全部提案。两者都必须经过预算和模拟执行，函数本身不直接生成成交。研究系统保存的用户回执和任务事件是审计对象，不能与策略信号混为一谈。

## 各层输入和输出

| 层 | 输入 | 输出 | 关键约束 |
| --- | --- | --- | --- |
| 数据 | 行情、财报、事件及来源时间 | 同口径、可追溯的点时数据 | 信号日不得读取之后才公开或修订的数据 |
| 因子 | 点时数据、因子算法和参数 | 每只股票、每个时点的因子值及缺失状态 | 保存版本、输入快照、价格口径和单位；缺失不得默认为 0 |
| 多个决策函数 | 同一时点可得的因子向量、各函数版本 | 各自的方向/评分、证据及提议目标权重 | 共同使用同一输入快照；函数之间保留分歧，不让单一输出直通订单 |
| 汇聚与预算 | 全部提案、函数组合政策、现有模拟持仓、现金、资金及风险预算 | 汇聚后的目标仓位、现金权重、分歧解释、目标金额或股数，或明确弃答 | 组合权重、冲突处理、单股和总风险上限事先固定 |
| 模拟执行 | 目标订单、下一时点可成交价格与交易状态 | 成交/拒绝、费用、现金和仓位流水 | 记录无法成交、股数单位、滑点和价格代理假设 |
| 评估 | 冻结决策、订单、行情与基准 | 收益、回撤、换手、交易胜率、相对基准 | 只使用事后成熟的结果；调参产生新版本和独立账户 |

可以把一次完整决策写作：

```text
F(t) = Factors(Data available by t)
P_i(t) = DecisionFunction_i,v(F(t))       # 每个函数独立提案
S(t) = P_1(t) 或 CombinePolicy_v(P_1(t), ..., P_n(t))
Target(t) = BudgetAndRisk_v(S(t), equity, cash, current holdings)
PaperFill(t+1) = ExecutionModel_v(Target(t), next available market data)
```

因子不必都等权，各决策函数可用规则、线性加权、排序、统计模型或优化器；汇聚层需另行固定函数权重、分歧处理和弃答条件。必须明确因子方向、标准化、缺失处理、训练窗口、权重和退出条件。组合预算使“买入”变成可核验的金额/股数。没有预算时，只能得到方向，不能评价真实可执行收益。

## “预算”至少有两层

1. **资金预算**：模拟账户初始资金、可用现金、现金缓冲、每只股票/行业/策略可分配金额、最大持仓和换手上限。它回答“买多少”。
2. **风险预算**：允许的组合波动、单一风险因子暴露、相关性、最大回撤或单次交易损失，以及触发后的降仓/暂停规则。它回答“最多承担多少风险”。

计算、数据与研究运行也可以有工程预算，但不参与买卖函数的资金约束。预算数值必须随策略版本冻结；它是实验条件，不应在看到模拟结果后回填旧账本。

## 本仓库当前状态

已实现的 SMA、动量和 Z 分数因子由三个单独策略在 `strategies.py` 内部使用，策略直接返回目标权重。`backtest.py` 的通用入口只消费按日期预先生成的目标仓位和日线；单策略函数只是一个适配器。`paper_execution.py` 只消费目标仓位、账户、未复权价格、买入单位和费用，不导入策略。当前 `strategy_simulator.py` 负责为单一 SMA 研究账户提供决策与行情，再把目标交给通用成交引擎，以 10 万元模拟现金、100 股买入单位和买卖各 0.05% 费用记账。这是**单策略回归账户**，不代表多个决策函数已经验证。多函数模式的 `decision_ensemble.py` 提供同输入快照的函数提案、显式权重汇聚、预算上限、来源哈希和分歧贡献。`decision_pipeline.py` 把单策略与多函数策略统一为日期化目标；`quant_paper_pool.py` 已把多函数政策接入独立前瞻模拟池，仍标为研究状态。目前只有总仓位和单股上限，尚无组合级波动、相关性或回撤风控。

独立的 `daily_factors_v2.py` 新登记六个日线候选计算器及三个待取得逐笔/盘口数据的因子；`daily_decision_rules_v2.py` 新增四个可组合的日线研究规则。它们保留可得时点、输入快照与研究状态，尚未进入现有政策、模拟账户或操作辅助。基线三股历史成交额大量缺失，涉及人民币成交额的规则在该样本上拒绝计算。验证要求见[因子研究 v2](factor-research-v2.md)。

当前实验政策已冻结三套函数、各函数同权、总仓位 80% 与单股 35% 上限，并建立独立账户，与单策略账户按同一未来日期、价格和成本口径并行比较。该账户另以买卖各 0.15% 的假设费用维持压力仓位和基准；至少 126 个未来交易日后才检查基础及压力收益是否超过各自基准、基础回撤是否不更差。通过也只产生人工复核候选。下一版需补充组合级风险预算、公司行动与可交易性核验；任何政策调整应建新账户。成熟的历史结果可以指导下一版本研究，但不得反向改变已登记的函数、预算、历史信号或旧账户订单。

## 进入辅助决策状态的门槛

“可辅助”是向人展示有依据的候选买卖、仓位范围、分歧和弃答原因，仍由人决定是否行动。至少要有完整的点时输入、多个函数的独立提案与组合血缘、预算和可交易性检查、冻结策略的前瞻模拟记录，以及对照基准、失败样本和稳定性报告。证据不足时输出“暂不建议操作”。当前两个模拟池未来交易日样本均为 0；多函数政策历史回看对费用高度敏感，尚未完成独立验证，所以系统未达到这个状态。
