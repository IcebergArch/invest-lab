# 多模型预测实验记录

`quant_lab.forecast_benchmark` 为同一规范化价格截面提供统一的滚动评估与只追加实验记录。默认实际执行两个轻量基线：最近收盘价（随机游走）和 20 日动量外推。外部时序基础模型只有在明确传入可运行的 `ForecastProvider` 后才会执行；列出模型名称、安装依赖或生成适配器代码均不等于完成了权重加载和 A 股检验。

量化空间的“预测模型实验”只读取主库与 Qlib 各自**最新的校验记录**，展示模型运行状态、5/20 步可比样本、覆盖率和相对基线误差；完整逐笔结果留在本地实验归档。研究空间中的荐股和买卖建议当前不使用这些预测模型的输出。

## 实验契约

- 从 `MarketStoreAdapter` 读取关注股日线，经 `CanonicalDailyBar` 归一化并生成共同交易日的前复权收盘价面板。原始价、前复权价与指数点位不能混算；面板的输入 SHA-256 包含来源、采集批次与价格。当前主库不具备完整的历史时点数据版本，输入指纹只说明本次读到了什么。
- `ForecastProvider.forecast(history, horizon)` 在每个起点仅接收截至该起点的收盘价；默认每隔 20 个共同交易观测取一个起点，比较 5 和 20 个观测后的目标。所有成功模型在同一股票、起点、目标日期上比较；失败模型单独标记，不把部分输出混进指标。
- 保存逐笔预测值、真实值、绝对误差、方向与可选分位覆盖；按预测窗口汇总收益率 MAE、相对随机游走改善、方向命中率与方向覆盖率，并记录实际覆盖的起点数。零方向的随机游走基线没有方向命中率。
- 每次运行保存模型 ID、权重 revision、评估设置、股票池、价格口径、数据截止日、输入指纹和完整逐笔结果；只追加 JSON 文件带 SHA-256 内容校验。还记录 Python 版本、平台、已安装的可选模型依赖版本及 provider 所在源码文件哈希，不加载重型依赖。`experiment_key_sha256` 标识相同输入、运行环境和设定，单次运行另有记录 ID。
- `point_in_time_validated=false`、`prospective_out_of_sample=false`。外部预训练模型与本地历史数据可能重叠，未核验训练语料前 `pretraining_overlap_status=unknown`。预测准确性不直接进入回测北极星分，也不转成买卖建议。

```python
from quant_lab.forecast_benchmark import evaluate_focus_benchmark, append_benchmark_record

result = evaluate_focus_benchmark("data/quant/market.sqlite3")
saved = append_benchmark_record("reports/quant/forecast-experiments", result)
print(saved["record_id"], result["input_fingerprint_sha256"])
```

| --- | ---: | ---: | ---: | ---: | ---: | ---: |

## 更广的 Qlib 固定 Release 试验

`quant_lab.forecast_qlib` 只读取已发布并逐文件校验的 2026-09-28 Qlib Release。它按交易所（SH/SZ/BJ）、首次股票区间年代（2010 年前、2010 年代、2020 年代）以及该区间是否在发布日前结束分层；每个非空层按固定 SHA-256 排序选最多 3 只。此版本共有 14 个非空层、40 只股票，其中 19 只的登记区间已结束。**区间结束不等于确认退市**；这种事后分层抽样也不是市场代表性样本。

每只股票独立用其有效收盘价序列做滚动检验，不要求 40 只股票在同一天同时有价格。选中样本共有 98,327 条有效收盘价和 3,883 个区间内缺失收盘值；39 只达到默认窗口的检验长度，另有一只北交所股票仅有 16 条有效收盘价。Qlib 的 `qlib_adjusted` 价格保持独立，**不与主库前复权价混合**。一个预测窗口的 5/20 步表示该股票随后 5/20 个有效收盘观测，停牌空值不会算作一步，故不同股票的实际日历跨度可能不同。

固定 Release 归档 SHA-256 为 `73f17f04b8710809f2881e20c3322990b39ecddf376f4b0e6d0c9acd0a6dede5`，本次输入指纹为 `dd3cbc507027b0712cd300622480a9c967cd31653fe5f4b110690a6306e0a9ba`。逐股来源文件 SHA-256、区间、缺失数、逐笔预测和运行环境写入 `reports/quant/forecast-experiments-qlib/2026-09-29/` 的压缩校验记录。归档数据是 2026-09-28 发布版本的回顾性视图，不能证明更早起点已知这些复权价格或股票区间。

| 模型 | 5 步样本 | 5 步收益率 MAE | 5 步相对随机游走 | 20 步样本 | 20 步收益率 MAE | 20 步相对随机游走 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 随机游走 | 4,691 | 4.88% | 0.00% | 4,660 | 10.05% | 0.00% |
| 20 日动量外推 | 4,691 | 5.61% | -14.95% | 4,660 | 14.81% | -47.40% |

上表把所有有效起点同权平均，因此长历史股票贡献更多。逐只股票先求平均、再对 39 只股票等权平均时，动量模型的相对误差改善分别为 -17.48%（5 步）和 -49.98%（20 步），方向一致。两模型对基线可比较样本的覆盖率都是 100%。

```python
from quant_lab.forecast_qlib import evaluate_qlib_cohort, append_qlib_benchmark_record

result = evaluate_qlib_cohort(
    "data/quant/qlib-releases/2026-09-28/published",
    "data/quant/qlib-releases/2026-09-28/qlib_bin.manifest.json",
    "2026-09-28",
)
saved = append_qlib_benchmark_record("reports/quant/forecast-experiments-qlib", result)
```

命令行使用 `PYTHONPATH=src python3 -m quant_lab forecast-benchmark --dataset qlib`；默认只运行两条基线，归档目录与主库试验分开。外部模型可在独立环境中加 `--provider chronos-bolt-tiny --chronos-revision <40位提交SHA>`，同时自动保留随机游走对照。首次广域外部模型试跑可调大 `--step` 或调低 `--per-stratum` 控制 CPU 推理次数，并在记录中保存实际设定。

## 接入候选模型

现有 `ForecastProvider` 是单变量收盘价接口，可以用它比较零样本模型的**单变量**输出。TimesFM 2.5 与 Chronos-Bolt tiny 已用固定权重完成本机 CPU 试验；Moirai、Tiny Time Mixers、Time-MoE、Timer 与 TFT 尚无本实验的运行结果。

### Chronos-Bolt tiny 实跑（2026-09-29）

独立 Python 3.12 环境安装 `chronos-forecasting==2.3.2`、Torch `2.14.0` 和 Transformers `5.17.0`，固定权重提交 `a0e552de83495b5c28c14c71c374f3e33280b340`。首次加载权重完成后，正式实验在离线模式运行。主库关注股用 120 个观测最小上下文、每 60 个观测一个起点；Qlib 分层 40 股用相同最小上下文、每 120 个观测一个起点。每次记录都同时重跑随机游走作为相同起点对照；这两组与上面的动量基线实验**起点间隔不同**，不能把表格中的误差直接交叉相减。

实际运行环境的全部 Python 包版本保存于 [Chronos 环境清单](../reports/quant/forecast-experiments/chronos-bolt-tiny-env-2026-09-29.txt)。模型环境放在服务进程以外；量化 API 仅校验并读取结果摘要。

| 数据与模型 | 5 步样本/覆盖 | 5 步收益率 MAE | 相对同起点随机游走 | 20 步样本/覆盖 | 20 步收益率 MAE | 相对同起点随机游走 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 主库 3 股：Chronos-Bolt tiny | 66 / 100% | 4.48% | -5.93% | 63 / 100% | 11.17% | -7.24% |
| Qlib 40 股：Chronos-Bolt tiny | 761 / 95.24% | 5.15% | -5.86% | 759 / 95.35% | 10.54% | -5.64% |

Qlib 有 1 股 `stock:600701.SH` 的预测被判无效：在 2021-04-02、5 步窗口，调整收盘价约 0.04345，模型第 1 步中位预测约 -0.00482，违反正价格约束。本实验保留该股及首次失败的股票、起点、窗口与错误类型，但不将该股任何部分预测并入汇总。Qlib 相对改善使用**Chronos 实际成功的同一批起点**上的随机游走误差；按成功股票等权汇总的改善为 -5.28% / -7.84%。10%–90% 预测区间实际覆盖为 80.81% / 75.49%，目前没有足够证据把该区间当作可靠风险限额。

完整逐笔及校验记录：[主库试跑](../reports/quant/forecast-experiments/2026-09-29/20260929T084613773725+0000-ad76335f4f034e6c8c629330375d37fc.json)、[Qlib 试跑](../reports/quant/forecast-experiments-qlib/2026-09-29/20260929T084806392625+0000-e3386e2482764d54848b13909cf2d959.json.gz)。实验说明的是该固定历史 Release 和当前复权版本上的回顾性预测误差；公开模型预训练数据是否与历史测试窗口重叠仍未知。

### TimesFM 2.5 实跑（2026-09-29）

独立 Python 3.12 环境安装 `timesfm[torch]==2.0.2` 与 Torch `2.14.0`，固定 Google 官方 `timesfm-2.5-200m-pytorch` 权重提交 `1d952420fba87f3c6dee4f240de0f1a0fbc790e3`。首次加载权重完成后，正式实验在离线模式运行。实际包版本见 [TimesFM 环境清单](../reports/quant/forecast-experiments/timesfm-2p5-env-2026-09-29.txt)。主库 3 股每 60 个观测选一个起点；Qlib 固定分层 40 股每 120 个观测选一个起点，最小上下文均为 120。每次都同时运行相同起点的随机游走基线。

| 数据与模型 | 5 步样本/覆盖 | 5 步收益率 MAE | 相对同起点随机游走 | 20 步样本/覆盖 | 20 步收益率 MAE | 相对同起点随机游走 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 主库 3 股：TimesFM 2.5 | 66 / 100% | 4.52% | -6.87% | 63 / 100% | 10.89% | -4.53% |
| Qlib 40 股：TimesFM 2.5 | 799 / 100% | 5.11% | -4.60% | 796 / 100% | 10.45% | -4.76% |

Qlib 5/20 步逐股先平均再等权时，相对随机游走为 +0.96% / -8.81%；这个聚合口径与按逐笔样本汇总的结果不同，不应挑选有利口径作为稳定性结论。5/20 步方向命中率为 46.06% / 48.87%，10%–90% 区间覆盖为 80.48% / 78.39%。当前检验没有证明优于简单基线，也没有验证训练数据与历史测试期是否重叠。完整校验记录：[主库](../reports/quant/forecast-experiments/2026-09-29/20260929T090059343597+0000-9a92a80b6c7642cbaeb93a948da3da59.json)、[Qlib](../reports/quant/forecast-experiments-qlib/2026-09-29/20260929T090420934307+0000-cf330a7f350741a698149a3cd19214c1.json.gz)。

多变量、未来已知协变量和不同频率的能力需要新增有时间戳的特征/可用时间契约，不能把今天查到的行业、财报、指数成分或公告回填到过去。TFT 等需要本地训练的模型应先固定训练、调参、测试时间段和股票池；测试段不得参与权重选择。基础模型还应记录预训练截止与语料覆盖，无法核实时单独标为未知。模型比较使用同一数据截面、相同起点、窗口、可用特征和评价指标；随后另做带成本、停牌、涨跌停和回撤约束的策略回测，避免把预测误差改善误报为可交易收益。
