# 市场脉搏：先看大势，再看少量行业大类

## 用法

```bash
PYTHONPATH=src python3 -m quant_lab market
PYTHONPATH=src python3 -m quant_lab market --date 2026-09-24
```

默认生成 `reports/quant/market-pulse.html`、Markdown 和同名 JSON；HTML 是可直接打开的大字静态报告，不需要网站服务。报告分别标明宽基和行业最新共同交易日；若申万接口比宽基滞后，不拿滞后行业数据解释较新交易日。`--date` 是两路数据各自的截止上限。

## 阅读顺序

1. 看沪深300、中证500、中证1000、上证指数、科创50的 1/5/20 交易日涨跌，判断大盘、大中小盘和成长板块是否同向。
2. 看 31 个申万一级行业上涨数量。它是**行业宽度**，不是上涨股票数量。
3. 看五条主线的 5 日表现和类内上涨数量，判断轮动是否集中。大类收益是内部申万一级指数等权平均，只用于观察，不能当作可投资指数。
4. 看成交份额较过去 20 个共同交易日均值的变化，结合涨跌判断相对成交关注度。份额上升但价格下跌，也可能是集中卖出；绝不称为“净流入”。
5. 如需下钻，再看报告中最近 5 日领先和落后的细分行业；不要求每天浏览 31 行业列表。

## 五条主线 + 其他的人工映射

这个分组是为了阅读简洁而做的产品层映射，**不是申万官方分类，也不暗示行业间资金可以直接相加为真实净流入**。每个申万一级行业恰好归入一个大类；代码在 `src/quant_lab/market.py` 的 `GROUPS`，运行时会核对库中的完整行业清单，分类变化时直接报错。

## “资金流向”能看到哪一步

当前库的申万行业指数包含源端成交额，宽基来源仅含价格和成交量。申万发布页展示成交额字段，代码保留其源端单位；报告只计算无量纲的同源份额和比例，不显示未经核对单位的绝对金额。`成交份额 = 该行业成交额 / 当日31行业成交额之和`，`份额变化 = 当日份额 - 前20个共同交易日平均份额`，`活跃度 = 当日成交额 / 前20日平均成交额`。这三个指标说明交易注意力在哪里，均无法识别买卖方向或投资者类别。

若要进一步研究“资金流向”，应另接并保存**口径明确的指标**：交易所股票成交额用来衡量活跃度，融资买入/偿还及余额变化反映融资交易，投资者持股变化反映持仓变化；这些含义不同，不能合成一个“主力资金净流入”。沪深股通披露机制已调整：当前沪深股通盘后披露成交总额及活跃证券成交总额，不提供可直接使用的每日买入减卖出净额；跨制度变更的历史比较必须保持同一口径。每项数据都要记录来源、发布时间、修订和缺失情况。

可核对的源：[申万指数发布页](https://www.swsresearch.com/institute_sw/allIndex/releasedIndex)、[上交所股票成交概况](https://www.sse.com.cn/market/stockdata/overview/day/)、[深交所每日成交金额](https://docs.static.szse.cn/www/market/periodical/month/W020260706503107241595.html)、[沪深股通披露调整说明](https://www.szse.cn/aboutus/trends/news/t20240412_606836.html)。

当前报告还没有全 A 股逐股涨跌家数、市值加权行业回报、真实资金净额，不能据此判断某类投资者正在净买入。

## 筛选、你的决定与复盘

`quant_lab run` 在市场报告上列出最多三个**行业待观察方向**，当前规则仅按过去 5 个交易日的等权行业表现排序，且必须为正。每个候选有独立 ID、规则版本、当时的行业成员清单及数据日期。行业数据落后时标记“等待行业数据更新”，不作为当日行动建议。

你可以直接在对话里告诉我保留、行动或跳过哪个候选；命令行也支持 `quant_lab decide <candidate_id> watch|act|skip --note "原因"`。这里的 `act` 只记录你的决定，**不会下单，也不是成交记录**。`quant_lab review` 计算该候选行业组未来 5/20 个共同交易日的等权指数收益；未到期则留空。这是方向复盘，不等同于个人账户盈亏。

当前没有用户决定与成熟结果。复盘样本不足 20 条时只展示证据，不自动调整筛选规则；达到门槛后仍需时间外验证，再提出有版本号的新规则与下一轮候选。
