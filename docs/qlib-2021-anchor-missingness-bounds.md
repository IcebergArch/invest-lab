# 锚定池未结算窗口的中位数界限

这份报告是**补算停牌窗口前**的冻结缺口界限；[停牌重放及更新后的界限](qlib-2021-anchor-halt-replay.md)将 500 个可清仓停牌窗口并回原有 6,144 个窗口分母。两版均保留，便于追溯估值假设如何影响结果。

[可复算报告](../studies/random-entry-baseline-v1/qlib-2021-anchor-missingness-bounds-v1.json)直接读取[6,144 个逐窗口账本](qlib-2021-anchor-conditional-returns.md)，由[计算脚本](../scripts/qlib_2021_anchor_missingness_bounds.py)生成。每组固定 768 个日历随机窗口，不删除停牌、退出或送转零股未决窗口，也不把其收益填成零。

对每个未结算窗口，分别设想其 **SMA 减同仓位等权** 的收益差低于所有已知值、或高于所有已知值。两个极端给出全组中位收益差的数学下界和上界；最大回撤差同法计算。报告另把触及 `SZ002202` 已知因子日期错位的完整窗口也当作未知，形成更保守的一组界限。下表显示**后一口径**，单位为百分点；负的回撤差表示 SMA 回撤更深。

| 2021–23 / 126 / 404 | 683 | 85 | [−1.214, −0.185] | [−1.979, −1.264] |
| 2021–23 / 252 / 202 | 610 | 158 | [−4.983, −0.706] | [−4.351, −2.201] |
| 2021–23 / 252 / 404 | 606 | 162 | [−4.789, −0.583] | [−4.194, −2.217] |
| 2024–26 / 126 / 202 | 612 | 156 | [−0.660, +2.247] | [−2.200, −0.762] |
| 2024–26 / 126 / 404 | 626 | 142 | [−0.449, +2.321] | [−1.813, −0.500] |
| 2024–26 / 252 / 202 | 562 | 206 | [+0.238, +5.237] | [−3.147, −0.543] |
| 2024–26 / 252 / 404 | 573 | 195 | [+0.200, +5.087] | [−2.967, −0.543] |

**已验证事实：** 早期四组收益差中位数即使让所有未知窗口取有利于 SMA 的极端值，仍为负；较晚段一年期两组收益差中位数即使取不利极端值，仍为正；较晚段半年期方向不能确定。八组回撤差中位数的**上界都小于零**。因此，单纯补齐这批未结算窗口的收益，无法把目前这八组的中位回撤结果变成 SMA 优于同仓位等权的证据。

界限只针对冻结窗口的**逐例等权中位数**，不约束收益尾部、均值或真实可交易收益。窗口之间共享日期、股票及种子，不能视作独立胜率；原价收盘撮合仍是代理，2021 Qlib 成分标签也没有官方历史时点确认。它是对回溯结果的缺口敏感性检查，**不是稳定策略或实际买卖点的验证**。
