# 一分钟读懂市场与资金口径

`quant_lab.flow_view.build_flow_view(market_report)` 接受 `build_market_pulse` 的结果，返回可直接放进静态报告的三句 `reader_lines` 和最多三条 `focus_points`。纯读取，不请求外部接口、不写数据库，也不生成交易指令。日期、来源 ID 和同步批次都保留在结果中。

阅读顺序：

1. **大盘涨跌**：五个观察指数有几个上涨、下跌，并标出宽基截至日期。它们不是全 A 股上涨家数。
2. **哪里交易更热**：五个行业大类的申万指数成交额占比，与前 20 个共同交易日平均值相比。每条同时显示该组行业指数当日平均涨跌，避免把放量下跌误读为利好。行业日期单独标出；若与大盘不同，报告明确不能把两日变化连成资金去向。
3. **资金方向**：`net_flow_available=false`。当前报告没有按投资者类别、融资账户或其他明确主体统计的买卖差额。成交额、成交占比和价格涨跌都不能证明某类资金净买入。

`focus_points` 按成交占比变化绝对值排序，最多取五个主线中的三条；“其他（综合）”不进入一眼阅读区。它衡量的是**相对成交关注度**，不显示未经核对单位的绝对成交额。`activity_available=false` 时不输出焦点方向。

## 已核实的数据边界

- 本地库 `daily_bars` 中有 31 个申万一级行业的源端成交额，最新共同日为 **2026-09-24**；五个宽基观察指数的最新共同日为 **2026-09-28**。这两天不能直接对齐。每个观测值有 `source_id`、`run_id`、`payload_hash`；视图返回来源和批次 ID。报告再次运行后应按新值核对，不能沿用这两个日期。
- [申万指数发布页](https://www.swsresearch.com/institute_sw/allIndex/releasedIndex)把字段标为“成交额”。成交同时有买方和卖方，不提供投资者类别或净买入方向。
- [上交所融资融券汇总说明](https://www.sse.com.cn/market/othersdata/margin/sum/)定义融资余额变化与融资买入、偿还之间的关系。这能作为未来接入的**融资账户增减**指标，但不能代表全市场资金净流向；当前库没有该序列。
- [沪深交易所关于 2024 年沪深港通披露调整的说明](https://www.szse.cn/aboutus/trends/news/t20240412_606836.html)指出，沪深股通盘后汇总披露成交总额及前十大成交证券总额；不能把现行汇总成交额写成北向资金净买入。

接入真正有方向的指标时，先明确**谁的资金、买卖或余额的定义、覆盖范围、发布日期、原始来源和缺失规则**，再对齐同一交易日。新指标另存独立字段与来源记录，不能覆盖成交关注度，也不能把不同主体净额相加为一个含糊的“主力资金”。
