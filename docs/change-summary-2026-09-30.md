# 2026-09-30 资本研究变更汇总

本轮交付分为数据快照和系统代码。数据包路径、大小、校验值及恢复步骤见[本地数据快照](data-archive.md)。原始行情、实验逐笔证据和运行账本通过 ZIP 保存；源码、配置、测试、文档及少量官方核验附件进入 PR。

## 系统能力

| 方向 | 本次实现 | 当前边界 |
| --- | --- | --- |
| 共享因子基建 | 分析与量化复用版本化因子存储、来源哈希和物化流程，补充日频因子及决策规则 | 日线数据；高频候选仍需独立数据源与验证，不能按高频效果宣传 |
| 多函数组合决策 | 决策函数生成提案，组合层汇总并施加仓位预算；通用回测与模拟执行消费日期化目标 | 单策略和多函数策略使用同一交易与收益评价合同；费用买卖各万分之五 |
| 仿真研究 | 2021 年后随机介入、跨年份与股票池回放，检查停牌、原价、整手、公司行动、缺失样本和费用压力 | 收盘成交是日线代理；当前研究尚未证明稳定的净收益优势 |
| 前瞻模拟池 | 单策略、暂定风险基线和多函数实验账户；冻结配置及代码哈希，同预算基准评价 | 截至 9 月 30 日仅各 1 个前瞻代理成交日，远未达到 126 日门槛 |
| 综合分析图 | 同一时间轴展示价格、因子、政策、指数调样、信息披露、策略信号和规则持仓；按类型启停、查看出处 | 公告和指数事件仍是核验过的有限子集，分别保留公告、生效与图上交易日 |
| 预测证据 | 报告预测原样追加保存，按最早同起点版本逐点核验后续事实及不变价基准 | 延迟生成、源数据变化及未到期预测分别标记；完整 20 步样本仍为 0 |
| 类型识别 | 共用规则识别标的状态，启用关联预测及子规则；独立 dev 策略模块 | 预先固定阈值，无模型训练；未注册现有冻结策略目录，未接账户执行 |
| 产品命名 | 页面和本地展示名称改为“资本研究” | 研究空间、量化空间继续共用底层数据 |

个人持仓收益不承担系统策略验证。预测捕获可手动遍历全部已入库股票；截至本轮主行情库仅有 4 只股票，当日捕获成功 3 只，不能视为已经覆盖全市场。

## 版本演进约束

目标流程为 `dev → pre_online → online`。dev 允许在预设范围内研究参数与规则；候选通过准出检查后冻结参数、代码和数据截面，进入 pre_online 回放与前瞻验证；达到门槛并完成人工核验后，发布新的 online 版本并保留回退点。正式入口为一个具备类型识别、子规则激活及组合预算的策略版本。

当前已落实预测留痕、dev 模块隔离和模拟账户冻结哈希保护，记录了阶段门槛。**完整的有界自动搜索、阶段晋级执行器和正式版发布系统尚未实现；online 尚无通过验证的策略。** 自动实验未来只能产出新候选，不能改写正在运行的参数。本轮未增加定时任务。

收尾时将曾修改公共策略文件的 dev 路由移入独立模块，恢复冻结账户依赖文件原字节；只读状态核验确认现有模拟账本与运行时哈希重新匹配，账户配置、参数及交易记录未改变。具体指纹和链路记录见[预测留痕与策略版本](forecast-evidence-and-lifecycle.md)。

## 证据与后续

本轮回归覆盖交易时序、费用、组合预算、因子版本、预测去重与迟发排除、来源修订、官方附件哈希、模拟账本冻结及数据包恢复。仅含待提交文件的临时副本通过全部 **318 项测试**；前端通过 TypeScript 与生产构建检查，Git diff 空白检查通过。ZIP 的 61,831 个数据文件通过 CRC 和 SHA-256 校验，5 个数据库实际恢复后完整性检查均为 `ok`。

历史回放和首日模拟收益是研究材料，尚不能推出稳定策略或交易建议。后续优先补齐带日期的股票池与公告覆盖、积累前瞻事实样本，并实现冻结候选的阶段门禁；晋级依据净收益、风险、预算对照和样本外表现，不能依据曲线贴合。
