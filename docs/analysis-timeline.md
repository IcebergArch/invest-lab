# 个股综合时间轴

个股分析页使用一张收盘价图叠加事件标记。图层可分别启停，时间范围可选近 120 日、近 250 日或全部已载入价格。多条事件落在同一交易日时合并为计数标记，点击后逐条显示事件原始时间、图上交易日、适用的生效时间、来源与证据。默认详情优先展示图窗内最近的公告或指数事件，再展示因子观测。公告/指数事件还列出标记日相对前一已载入收盘、以及随后 5 个已载入交易日的价格变化；跨价格断点或图窗不完整时留空，不作事件归因。图窗起止日与载入价格点数直接显示，未出现在图上的旧事件不被当成当前窗口内的事件。

`analysis_timeline.py` 只消费已有报告、本地官方资料审计和人工核实事件登记，不修改因子库或量化决策：

| 图层 | 现有来源 | 时间口径与覆盖 |
| --- | --- | --- |
| 特征因子 | `factors.sqlite3` 的同版本最近观测 | 观测日标在价格日线上；事后归档不冒充历史首次可得时间 |
| 政策公告 | `data/quant/reviewed-policy-events.json` | 仅人工审核的少量宏观公告；盘后或仅有日期精度时标在下一交易日，原公告时间和生效日保留在详情 |
| 中证指数成分 | 经官方附件核实的 `csi300-official-2021-06-delta-audit-v1.json` 与 [`reviewed-index-events.json`](../data/quant/reviewed-index-events.json) | 2021 年 6 月沪深 300 的 25 入 25 出一轮，以及 2026 年 6 月中证 A50 调入洛阳钼业一行。图上标在收盘后生效的下一已载入交易日，详情保留公告日和生效日；读取时核对官方附件 SHA-256。其余调样不推定 |

API 的 `analysis_timeline` 字段按事件类型输出可得状态，事件对象分别保存 `event_at`、`effective_at` 与 `anchor_date`。后续接入公告或更多官方指数调样，应先保留源文件、发布时间、修订与生效时间的证据，再扩展该字段；不从价格或因子变化反推公告。
