# 40 股群体价格与相对量能预测试验

这是独立的离线研究试验，不接入荐股排序、在线策略或自动交易。它检验一个较小的问题：**在已知的 40 股固定样本中，过去的群体涨跌、涨跌家数和同股相对量能，能否预测未来 5/20 个交易日的群体收益代理？** 这里的“群体行为”仅是可观察行情的代理。数据不包含机构或散户身份，也没有真实净买卖额；不能把预测或指标称为资金流。

## 数据与研究对象

复用 [Qlib 固定 Release 及 40 股分层样本](forecast-benchmark.md)。读取前核对 release manifest，随后逐文件校验 `close.day.bin` 和 `volume.day.bin` 的大小与 SHA-256。40 股来自 2026-09-28 发布版本的事后分层，包含登记区间后来结束的股票；这保证试验可复现，却**不是历史时点可知股票池，也不代表全 A 股**。主库和 Qlib 价格不混用。

Qlib 的 [官方数据说明](https://github.com/microsoft/qlib/blob/main/docs/component/data.rst)提示其 `volume` 可能经过复权。因此本试验只计算**同一股票相邻两个交易日**的 `log(volume_t / volume_(t-1))`，不跨股票相加为原始股数或资金金额。相对量能在绝对值超过 `log(4)` 时截断，并记录截断次数；这降低公司行动等跳变对模型的影响，不能消除数据口径风险。缺失或非正的收盘价、量能不进入该日配对。2021 年以来的 1391 个交易日均达到至少 20 只有效配对的门槛；实际群体样本仍随日变化。

每日群体收益代理是当日有效配对股票的**简单等权收益平均**。未来 5/20 日目标是把后续每日群体收益复合。停牌、缺量或退出样本不会被悄悄补值；某一天配对少于 20 只则该日及跨越它的样本不可用。这是观察指标，不能据此计算可成交组合收益。

## 固定实验方案

- 从 2021-01-04 起，每 20 个日历中的交易位置选一个常规预测起点。每个起点收盘后才读取当天特征：当日群体收益、过去 5 日复合收益、上涨减下跌家数占比、同股相邻日价格方向乘以截断量能变化的平均、截断量能变化平均、当日有效配对占 40 股的比例。
- 对每个预测起点和 5/20 日目标，使用最近最多 504 条**标签截至该起点收盘已经完成**的日度训练样本；至少需要 120 条。特征只用各自起点及之前的行情。每次重新估计标准化岭回归，惩罚系数固定为 30，预测收益截断在 ±30%。这些参数在读取结果前固定，不针对事件或结果调优。
- 零收益基线预测未来群体收益为 0。模型与基线在**完全相同的起点和目标**上算平均绝对收益误差；技能值定义为 `1 - 模型 MAE / 基线 MAE`。技能值低于 0 表示模型较差。早期训练标签不足的起点记为未覆盖，不补造模型预测。
- [经核对的央行事件登记](../data/quant/reviewed-policy-events.json)另作压力诊断。载入时复用事件登记的完整结构校验；只接受官方发布已核实且至少核实公告日期的事件，否则整个试验失败，不悄悄纳入不可靠事件。起点采取保守规则：公告只有日期、或网页显示时分却只能核实日期时，一律选公告日前一交易日收盘；只有公告钟点经过核实且明确晚于收盘时，才可选同日收盘。当前四个事件均只有日期级可用性核实，所以 2022 与 2023 年网页显示傍晚时分的降准公告也回退到前一交易日收盘。这是事后压力诊断的起点，不表示公告日盘中完全没有其他信息。事件名称和未来反应**不作为模型特征**。四个宽松事件样本极小，政策常与其他措施同日出现，不能用其差异调参或做因果归因。

完整记录为压缩 JSON，包含每个常规与事件起点的日期、目标日期、六项起点特征、训练样本数、最后一个已成熟训练标签日期、实际收益、模型预测、零收益基线、双方误差、样本覆盖与失败计数；另有来源文件、经校验事件的规范化记录、**源事件登记文件的原始字节哈希**、起点规则及实现哈希。每次运行追加新文件，并在读取时验证记录摘要。

运行：

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m quant_lab.group_behavior_pilot
```

## 下一步数据条件

要研究真实成交行为和“价格上涨但企业价值未同步提升”的假设，需补充时点可查的原始成交量、成交额、可交易状态、财报及披露时间、估值分母与盈利预期修订。价格、量能代理无法识别谁在买卖，也无法证明企业基本面没有变化。进入策略评估前还需重建当时可见股票池、冻结逐日数据版本，按开盘可成交价格、费用和 A 股约束计算收益。
